## Who I Am

I'm a builder from Kerala, India. I don't specialize in one stack — I build whatever the project demands: a 182K-line Go CLI platform, a Rust code transformation engine, a 24-agent autonomous engineering organization, a zero-dependency Python search engine, a complete AI operating system, a programming language, a post-quantum cryptography suite, and multiple SaaS products that served hundreds of real users. I've shipped **204+ repositories** across 12+ languages. Every line of the early work was written by hand — AI acceleration came later, as a multiplier on existing craft.
